# 日语抽背训练器

一个简单的桌面小工具，用来抽背日语假名、单词和例句。支持随机出题、输入答案、自行核对。

## 功能
- 四种模式：平假名、片假名、单词、例句
- 随机出题
- 查看正确答案

## 运行
1. 安装依赖：
   ```bash
   pip install PySide6
   ```
2. 启动程序：
   ```bash
   python main.py
   ```

## 数据格式
数据文件位于 `data/` 目录，均为 JSON 数组。每一项包含：

```json
{
  "question": "犬",
  "answer": "いぬ / 狗"
}
```

如需扩展内容，按上述格式新增即可。

## 常见问题
- 启动后没有题目：请确认已经选择模式，或检查对应的 JSON 是否为空。
